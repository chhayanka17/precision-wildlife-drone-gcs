# 📌 Overview

The **Precision Wildlife Contraceptive Delivery Drone System** is a simulation-based Ground Control Station (GCS) prototype designed for humane wildlife population management.

The system demonstrates a complete drone operation workflow including:

- Mission planning
- Real-time telemetry monitoring
- Wildlife detection simulation
- Automated intervention authorization
- Payload deployment workflow
- Fail-safe landing & recovery logic
- Event logging and monitoring

Built during a **24-hour hackathon**, the project focuses on operational workflow design and rapid prototyping of a real-world drone management system.

---

# 🌳 Problem Statement

Wild boar overpopulation contributes to:

- Crop destruction
- Ecosystem imbalance
- Economic losses
- Rising human–wildlife conflict

Existing solutions such as culling or relocation are often temporary, expensive, or ethically controversial.

There is currently no scalable and precision-based wildlife population management workflow suitable for safe autonomous intervention.

---

# 🧠 Proposed Solution

This project simulates an AI-assisted drone workflow capable of:

✅ Detecting wildlife using simulated RGB/Thermal feeds  
✅ Identifying wild boars through rule-based verification  
✅ Authorizing humane intervention actions  
✅ Simulating edible contraceptive pod deployment  
✅ Triggering autonomous fail-safe landing procedures  
✅ Logging mission and safety events in real time

## ⚙ Intervention Logic
The system authorizes intervention when:

- Species = Wild Boar
- Confidence > Threshold
- Battery level safe
- Target inside mission zone
